# 🏥 MediCare – Hospital Appointment Management System

🔗 Live Demo: https://hospital-appointment-management-system-hnuhnifac-rahul-raj-bnki.vercel.app/login

## 🚀 Overview
MediCare is a full-stack Hospital Appointment Management System that enables patients to register, log in, browse doctors, and book appointments online. The project includes secure authentication, appointment scheduling, and admin functionalities.

## ✨ Features
- Patient Registration and Login
- Secure JWT Authentication
- Doctor Listing with Consultation Fees
- Appointment Booking System
- Admin Dashboard
- Responsive User Interface
